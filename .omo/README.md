# .omo/ — machine artifacts only（只放机器产物，不放文档）

> Convention per decision **D13** (see `docs/release-process.md` / `_zh-CN.md`).
> **Rule: human-readable documentation lives in `docs/` (hand-written, bilingual
> twins, reviewable); this directory holds ONLY machine artifacts — data and
> evidence the automation reads and writes.** Nothing here is documentation;
> nothing in `docs/` is machine data.
>
> 规则（决策 D13）：**给人读的文档放在 `docs/`**（手写、双语成对、可评审）；**本目录只放机器产物**——自动化读写的数据与证据。这里没有文档，`docs/` 里没有机器数据。

## Tracked（入库）

- `compat.yaml` — the three-party compatibility matrix **single source of truth**
  (machine-readable). Rendered into `docs/compat-matrix.md` / `_zh-CN.md` by
  `scripts/render-compat-matrix.mjs`.
- `README.md` — this convention note.

## Untracked / local（不入库，本地）

- `evidence/` — per-matrix-row `concerto_verify` records (release gate 8 reads
  them via `scripts/check-l2-evidence.mjs`), manual probes, fix logs. Audit
  trail, not documentation.
- `release-notes-<v>.md` — transient, generated by `scripts/release-bump.mjs`
  during a release.
- `legacy/` — historical opencode-era working state (boulder/drafts/notepads/
  run-continuation/start-work), archived 2026-09-05, **frozen**.
- `plans/` + `evidence/task-N-*.log` + `evidence/smoke-real-*/` — rc-era
  (opencode + omo) task ledgers and evidence. Frozen; still referenced as
  historical pointers by `docs/mvp-pitfalls*.md`.

## The split going forward（今后的分工）

| Content | Where |
|---|---|
| 过程文档 process docs (release / install / pitfalls / verification reports) | `docs/<name>.md` + `docs/<name>_zh-CN.md` — human-authored, reviewed, versioned |
| 过程数据 process data (matrix rows, verify evidence, probe logs, release notes) | `.omo/` — machine-written, machine-checked, never hand-edited |

**协奏模式的过程文档 → `docs/`（沿用现有模式）；只有矩阵数据与验收证据 → `.omo/`。**
Concerto process documentation keeps going to `docs/`; only matrix data and
verification evidence stay in `.omo/`.
